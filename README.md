# Oxpecker

Oxpecker is a modpack for Minecraft NeoForge 1.21.1 built to quite literally build anything engineering related. With Sable, CC, and Create as the big pillars, the combinations that can be done are ridiculous.
Link: https://modrinth.com/modpack/oxpecker

### What is to offer?

![Plane and Drill Machine Side By Side](https://cdn.modrinth.com/data/cached_images/3bea28d5aede4c0a57367aad8a5c206632663e63.jpeg)

### Aeronautics

The pack includes mods such as Create Aeronautics, Create Propulsion, Automobility, and Immersive Aircraft to let you build custom airships, planes, and land vehicles. Instead of sitting static, your assemblies can be free to fly, float, drive, and fall realistically based on propulsion, gravity, kinetic impact, and weight.

![CC and Security Craft stuff](https://cdn.modrinth.com/data/cached_images/c9388f16b85a178708dd28882b74c213cbb291c2.jpeg)

### ComputerCraft

Oxpecker adds programmable computers directly into your world using CC: Tweaked. You can type code straight into these game terminals and pair them with extensions like HUD Glasses, Advanced Peripherals, CIDE-CC, and wireless modules to monitor data pipelines, build automated machines, or write factory scripts.

![Controllers of all kinds](https://cdn.modrinth.com/data/cached_images/b9cbc7273ac157ac883d938456147b0082f52ec4.jpeg)

### Create Cannons and Adjacent Mechanics

The pack includes heavy-duty artillery from Create Big Cannons, Create Big Cannons: Advanced Technologies, and Arsenalists of Create. These mods bring ballistic physics and explosions into the game, allowing you to design projectile trajectories.

![7 different bearings as display](https://cdn.modrinth.com/data/cached_images/6e2678149edb9add5e2027f73ac3553cc18b8d82.jpeg)

### Sable Engine Tools

Oxpecker has a massive chunk of Sable mods, such as Physics Compat, Sable Beyond, Sable Photomancy, and Drive-By-Wire with Sable. These tools allow almost everything in the game, including CC, to interact with physics. You can use ComputerCraft terminals and electronic switches to directly plug into, pilot, and calculate the live movement of your sublevels and vehicles.

![Sliding Aeronautics/Sable system](https://cdn.modrinth.com/data/cached_images/1513233b038cdf116782ef7ed5de337b62e15c7c.jpeg)

### Optimization Mods

To keep your computer running smoothly when playing, the pack uses background performance engines such as Sodium, Sodium Extra, FerriteCore, Entity Culling, and ModernFix. These libraries optimize memory allocation, clean up hidden textures, and reduce stress so that Sable can run without causing heavy lag or freezes.

![Cliff Shot](https://cdn.modrinth.com/data/cached_images/ce0a2213e25bedecaf16c33f404d1540838dcc86.jpeg)

### Cinematography Mods

For recording high-quality videos and getting elite screenshots, Oxpecker features tools such as Do a Barrel Roll, Zumey, and Complementary Shaders (Reimagined and Unbound). These additions add camera controls and cinematic graphics to capture your machines in action from any perspective. For reference, every image on this page is a raw screenshot from ingame using F2, F6 (Zumey), and/or F4.
